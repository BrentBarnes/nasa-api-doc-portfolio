# NASA API Documentation Portfolio

A technical writing portfolio showcasing NASA API documentation built with Docusaurus.

## Overview

This project demonstrates technical writing skills through comprehensive documentation for NASA APIs. The site is built using Docusaurus, a modern static website generator optimized for documentation.

## Features

- Clean, professional documentation site
- Custom NASA-themed styling
- Responsive design
- Dark mode support
- Easy navigation and search

## Getting Started

### Prerequisites

- Node.js >= 20.0
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/BrentBarnes/nasa-api-doc-portoflio.git
cd nasa-docs-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The site will be available at `http://localhost:3000`.

## Available Scripts

- `npm start` - Start the development server
- `npm build` - Build the site for production
- `npm serve` - Serve the production build locally
- `npm clear` - Clear the Docusaurus cache

## Project Structure

```
nasa-docs-portfolio/
├── docs/              # Documentation markdown files
├── src/
│   ├── components/   # React components
│   ├── css/          # Custom CSS styles
```
